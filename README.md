# Siren

**No AI-Coding Allowed.**

Siren is a real-time communication platform built with Rust.  
It's a backend platform that allows users to send messages to eachother, communicate using voice/video calls, and do screensharing.
It should be able to connect to any frontend platform: web, desktop, mobile...
